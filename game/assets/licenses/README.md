# Lizenzen — integrierte Drittassets

Dieses Verzeichnis enthält Kopien der CC0-Lizenztexte der integrierten Packs.
Die **verbindliche Attribution** für CC-BY-Assets (poly.pizza) steht in der versionierten
Root-Datei [/ATTRIBUTIONS.md](../../../ATTRIBUTIONS.md). Der vollständige Audit mit
Freigabeentscheidungen: [docs/assets/asset-license-audit.md](../../../docs/assets/asset-license-audit.md).

- CC0-Assets: Namensnennung nicht erforderlich (Kenney, KayKit, Quaternius, OpenGameArt-CC0-Stücke).
- CC-BY 3.0 (poly.pizza): Namensnennung **Pflicht** — siehe /ATTRIBUTIONS.md.
